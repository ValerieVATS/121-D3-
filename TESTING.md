# Manual test script

For a person, or an agent driving a browser. Run `deno task dev` and open the local URL with `?seed=121`. Before each section, reload. To read logical state, use `game.state` in the console. To read what has played, use the panel beside the grid, including the `#live` text, or look at the marker.

**Promotion rule:** a bug found by hand or by an agent becomes a permanent test in `core/` before it is fixed, unless it truly lives in `game/`, in which case add a step here.

| #  | Action                                                                           | Expected observation                                                                                                                                           |
| -- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1  | Load the page                                                                    | One canvas. A pale marker at the center of a green map. No console errors.                                                                                     |
| 2  | Tap the right arrow                                                              | The marker slides one cell east. `#live` says `moved to 1, 0`. `player` is `{ x: 1, y: 0 }`.                                                                   |
| 3  | Walk until lake or mountain is ahead, then press toward it                       | The marker lurches and flashes red, then returns to its cell. `#live` says `blocked by lake at ...` or `blocked by mountain at ...`. `player` has not changed. |
| 4  | Tap an arrow during a walk                                                       | The tap waits. The marker finishes the walk, then takes that step. It never skips a cell.                                                                      |
| 5  | Mash arrows quickly, then stop                                                   | The marker settles on the cell `player` reports.                                                                                                               |
| 6  | Hold an arrow down                                                               | The marker keeps walking. Holding into a wall repeats the bump.                                                                                                |
| 7  | Load `?seed=7`                                                                   | A different map.                                                                                                                                               |
| 8  | Run `game.state` in the console                                                  | Plain data: `seed`, `player`, `inventory`, and `changed cells`. No terrain list.                                                                               |
| 9  | Press an arrow several times                                                     | Position and Terrain in the panel update with each movement. The marker catches up to the player position after its animation.                                 |
| 10 | Make the window short, then press the down arrow                                 | The page does not scroll. The marker moves.                                                                                                                    |
| 11 | Click the sound button, then press an arrow                                      | The button reads `Sound: off`, and the arrow still moves the marker.                                                                                           |
| 12 | Click the sound button again                                                     | The button reads `Sound: on`, and you hear a two-note chime.                                                                                                   |
| 13 | Tab to the sound button and press Space                                          | It toggles. Arrow keys still move the marker.                                                                                                                  |
| 14 | Listen while walking and bumping (headphones or speakers)                        | A soft tick on each step, and a low buzz on each bump, and a two-toned sound when gathering. **This is the only check that a person can hear them.**           |
| 15 | On a high-resolution display, or at browser zoom 200%                            | Grid edges stay sharp. The marker stays centered. Run `document.querySelector("canvas").width`: it is the canvas `clientWidth` times `devicePixelRatio`.       |
| 16 | Stand on grassland or trees where lake or mountain is not adjacent, then press G | The player gathers feathers/sticks, not moss or rocks. `#live` reports the gathered item, and inventory increases by one.                                      |
| 17 | Without moving, press G again on the same cell                                   | `#live` reports `nothing available to gather`. Inventory should not increase again.                                                                            |
| 18 | Stand beside a lake, then press G                                                | The player gathers moss. `#live` reports `gathered moss`, and inventory should increase by one.                                                                |
| 19 | Stand beside a mountain, then press G                                            | The player gathers stones. `#live` reports `gathered stones`, and inventory should increase by one.                                                            |
| 20 | Press G while a movement animation is playing                                    | Gathering should wait. The marker and `player` position remain consistent.                                                                                     |
| 21 | Gather from a cell, walk away, then return                                       | The depleted cell remains visibly darker, even after leaving and returning to it                                                                               |
| 22 | Press G when no resource is available                                            | `#live` reports `nothing available to gather`. Inventory and world state remain unchanged. No sound plays.                                                     |
| 23 | Run `game.state` in the console after gathering                                  | `inventory` contains the gathered item count. `changedCells` contains only modified cell coordinates. No complete terrain map is stored.                       |
| 24 | Mash G and arrow keys quickly, then stop                                         | Commands wait for the presenter. The marker eventually settles on the cell reported by `player`.                                                               |
